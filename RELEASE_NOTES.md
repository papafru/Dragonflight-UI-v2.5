# fruUI v1.3.6 — Stable

Stable edition: **original Dragonflight UI: Reforged appearance**, plus recent functionality improvements.

**Included:** Edit Mode has readable drag labels and stable position handles for Target, Target of Target, buffs, enchant icons and quest frames. Mouseover keybinding mode supports explicit **Save Changes / Cancel**, Escape over a hovered action button clears its binding provisionally, and Escape elsewhere cancels unsaved changes. Left and right mouse buttons are excluded as assignable binds.

**Excluded:** Modern Dark themes, redesigned bars/frames, minimap and cast bar aesthetics. These remain in the [testing branch](https://github.com/papafru/fruUI/tree/testing).

**Addon-manager installation:** Download `DragonflightUI-Reforged-v1.3.6.zip`; its only top-level folder is `DragonflightUI-Reforged`. The TOC should be at `Interface/AddOns/DragonflightUI-Reforged/DragonflightUI-Reforged.toc`.
