# fruUI

A customized build of **Dragonflight UI: Reforged** for World of Warcraft 1.18 / classic 1.12 API, with additional mouseover keybinding functionality.

## Original project

Based on [Dragonflight UI: Reforged](https://github.com/Stormhand-dev/DragonflightUI-Reforged), originally by Guzruul and reforged by Stormhand. Original project assets and attribution are retained.

## Mouseover keybindings

Use `/kb` to enter or leave keybinding mode. Hover over an action button and press a keyboard key or mouse button (except left-click); mouse wheel directions and modifiers are supported. Escape while hovering clears a button's bindings.

**Compatibility:** This build is intended for the WoW 1.18 client with 1.12-era API. In-game testing is still required.

## Installation

Copy the addon folder `DragonflightUI-Reforged` from the repository into `World of Warcraft/Interface/AddOns/`, then reload the interface.
